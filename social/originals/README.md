# Originals

The site's first gallery photos as they came off the phone, before any blur.
They used to be served from `/images/` as `unnamed (N).webp`. On 2026-10-16
the site switched to the blurred copies `social/tools/prep-photos.cjs` makes
(saved as `/images/<car>-<place>.webp`), because one of these shows a house
number. This folder isn't served (`_config.yml` excludes `social/`).

Never link to these from a page. A new photo for the site comes from
`social/photos/`, which is where the blur boxes have already been applied.
